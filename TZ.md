# CubeTrainer

## 1. Цель проекта

Разработка веб-сервиса для спидкуберов (людей, собирающих головоломки на скорость), который решает проблему отсутствия глубокой аналитики прогресса и синхронизации данных между устройствами. Сервис предоставляет профессиональный таймер, генератор случайных состояний (скрамблов) согласно стандартам WCA, а также инструменты для визуализации динамики результатов (графики, тренды).

## 2. Роли пользователей
* Гость: Имеет доступ к таймеру и генератору скрамблов. Результаты хранятся только в локальном хранилище браузера (LocalStorage) и теряются при очистке кэша.
* Авторизованный пользователь: Сохраняет историю сборок в облачную БД, может создавать разные сессии тренировок, просматривать глобальную статистику, графики прогресса и экспортировать данные.
* Администратор: Управляет типами головоломок, модерирует пользователей, имеет доступ к панели Django Admin для управления базой данных.

## 3. Модели данных

* ### Discipline (дисциплина: классический 3x3, 3x3 одной рукой, 2x2 и т.д.)
    #### Назначение: Справочник поддерживаемых дисциплин (3x3, 4x4, Pyraminx и т.д.).
    #### Ключевые поля:
  * name (String): Название (например, "Rubik's Cube 3x3").
  * slug (Slug): Уникальный идентификатор для URL.
  * scramble_algo (String): Идентификатор алгоритма генерации (нужен для выбора логики скрамблинга).
  * is_wca (Boolean): Является ли дисциплина официальной.

* ### Session (Тренировочная сессия)
    #### Назначение: Группировка сборок. Позволяет разделять тренировки.
    #### Ключевые поля:
  * user (ForeignKey): Ссылка на пользователя.
  * discipline (ForeignKey): Ссылка на discipline. 
  * created_at (DateTime): Дата начала сессии.

* ### SolveRecord (Запись сборки)
    #### Назначение: Хранение данных о конкретной попытке сборки.
    #### Ключевые поля:
  * session (ForeignKey): Ссылка на сессию.
  * time_ms (Integer): Время сборки в миллисекундах.
  * scramble (Text): Строка скрамбла, по которому производилась сборка (для воспроизведения ситуации).
  * penalty (ChoiceField): Штраф (0 = чисто, 2000 = +2 секунды, -1 = DNF/Не собрал).

## 4. Ключевой функционал
* Генерация и Трекинг: Пользователь выбирает дисциплину, система генерирует корректный скрамбл (последовательность ходов). Пользователь запускает/останавливает таймер (пробелом или касанием), система фиксирует время и автоматически рассчитывает текущее среднее (Ao3/Ao5/Ao12/Ao50).
* Аналитика сессии: При завершении тренировки пользователь нажимает "Завершить сессию". Система рассчитывает статистические показатели: лучшее время (PB), среднее арифметическое, стандартное отклонение (стабильность) и сохраняет сессию в историю.
* Визуализация прогресса: Пользователь переходит в профиль, где система строит график динамики результатов за выбранный период (неделя/месяц), накладывая линию тренда на «облако» всех сборок.

## 5. Внешние интеграции / Аналитика
* Pandas. Используется на бэкенде для вычисления среднего(и других метрик) по большому массиву исторических данных пользователя, чтобы сгладить случайные выбросы и показать реальный тренд улучшения навыка.
* Генерация скрамблов с PyTwist/kociemba. Реализация сложной математической логики генерации случайного состояния кубика Рубика (не просто случайные ходы, а случайное положение элементов).
